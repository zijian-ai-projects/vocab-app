# 小学 / 初中释义覆盖层（V1.3.4）

## 作用域与来源边界

全部词表由民间整理。本层不是官方词表审计，也不是重建通用词典。
[通用 bank](<../data/bank.json>)、[原词书](<../data/books.json>)、[词组](<../data/phrases.json>)和[词组书](<../data/phrase_books.json>)沿用V1.3.3原字段、稳定key、成员和顺序。

[显示覆盖](<../data/level_meanings.json>)包含全部小学1,478个成员、初中4,007个成员（含773个中考词组），适用于真实词书、分组并集及教材系列。
显示卡片、目录、悬停提示和四个学习选项均使用当前学段；高中及以上、通用词汇量测试仍用原bank。
不在UI显示难度标签，不更改词性、音标、频次、难度、记忆状态、排期或历史。

## 离线可复现规则

[生成器](<../scripts/build_level_meanings.py>)的规则为 `school-meaning-overlay-v3-community`。
54个来源输入包括四份原数据、49份[学校gloss快照](<../data/school_gloss/>)和快照索引；输入SHA将CRLF归一成LF。
不依赖Git忽略的build中间目录，不联网。默认及 `--check` 均只读；只有明确的 `--write` 重建覆盖文件。

首选经核实的完整中文首义片段，再按学校常见词性、首义和原文上下文选择；小学不超过32字/1义组，初中不超过58字/2义组。
固定选择器必须在已散列本地来源中找到原文字面片段，不能虚构替换词典文字；专业、粗俗、俚语、人名/姓氏标签不自动作为普通学校义。
同形异义及旧库大小写折叠另做限定原文片段选择，不改稳定key。
每条输出保留来源路径、规则和散列，运行时只向词条浅拷贝添加 `display_s / level_s`，缺失/损坏/空值安全回退通用义。

## 尚需逐词审核的回退池

`review_required` 为小学47项、初中136项，25词重叠，158个不同词；这是普通通用首义回退池，不等于158项全错。
本版尚未完成这158词逐词上下文审核。`alice / matt / bds` 保留通用bank义，并明确列出待核实备注，不能把疑似人物或导航缩写猜译为已经核实的学校释义。
773个中考词组使用通用首义回退，不混入单词复核池。
