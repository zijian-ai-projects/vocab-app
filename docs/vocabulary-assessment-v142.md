# V1.4.2 词汇量测试：方法契约与研究边界

## 定位与推荐表述

> 采用词频分层与 IRT/CAT 思路，在本地有效词目范围内估计书面词义识别量。题目参数来自启发式词频先验，尚未经学习者作答数据标定；结果不是官方 VST 分数，也不等同于词族量、考试等级或语言能力认证。

本版本借鉴 VST 的分层抽样、IRT 的概率建模和 CAT 的自适应选题，不宣称复制 CATSS 或 VCheck，不使用“首个”“最成熟”“精准测出真实词汇量”等未经证实的表述。

## 1. 文献实际支持什么

| 工具 | 可核实的题型、范围与计量 | 不应外推的结论 |
| --- | --- | --- |
| **VST，Nation & Beglar（2007）** [1][2] | 原版从 BNC 词族表抽样（前 12 层曾按 BNC 口语部分重排），设 14 个千词族层，每层 10 题，共 140 道四选一释义识别题；目标词附短而不直接释义的例句。原计分为总正确数乘 100，单位是按 Bauer–Nation level 6 组织的 **word families**。后续 20,000 版为 100 题，乘数改为 200。 | VST 本身不是 CAT。它测书面接受性词汇，不直接测听力、产出能力或整体阅读能力。原版不设“不认识”，也不作猜测扣分；不能给本地改编题直接套用原版乘数、等值或信效度。 |
| **CATSS，Laufer & Goldstein（2004）** [3] | 双语题覆盖主动回忆、被动回忆、主动识别、被动识别；依次涉及从意义回忆英文、从英文回忆意义，以及两个方向的识别。原文采用 VLT 式词表片段：前 2,000 词、第 3/5/10 千词及 AWL，各 30 个目标词，共 150 词、至多 600 个模式题。AWL 跨频率范围，不是额外一个等容量千词层。 | 文中自适应主要是同一词按强到弱循环，答对后不再测试较弱模式。435 人研究为检验强度层级而用纸笔施测；跳级、停测阈值由测试者设定，文中明确留待进一步研究。不能把其名称当作本地固定 3PL 或最大信息量选题已获验证的证据。首版不实施其回忆/强度测量。 |
| **VCheck / WordEngine** [4] | 开发方 2013 年 FAQ 称其为 IRT/CAT：2006 年起初主要是词/伪词的词汇判断（LDT），2012 年组合释义题估计理解。开发方当时描述约 50,000 个 **Base Words** 的词库；这些单位与 VST 词族不同，通常合并屈折形式、分别处理派生形式，还可包含部分多词单位。难度 lexit 来自作答数据，而不是词频名次本身。 | 该资料是开发方历史说明，不是独立工具比较或对当前版本的审计。其区分已标定与估计难度，测试能力只用已标定词；公开资料不提供可直接复现的完整题库、参数和联合评分算法。不能声称复制其标定、准确率或商业系统。 |

VST 官方规格指出：每层题数不足以可靠测量该层掌握程度，分层首先服务于总量抽样；词频也不是已知/未知的硬边界 [2]。2007 原文曾允许初中级学习者测至能力以上若干层，后续规格则强调全范围覆盖，避免遗漏低频但已知的专业词、借词等 [1][2]。

Stoeckel、McLean 与 Nation 的后续论文明确指出三类误差：释义选择中的猜测/答题策略、由一个词族成员推断其他成员、稀疏抽样的代表性不足 [5]。因此不能借用早期测试的声誉，替短测或新题库作准确性保证。

## 2. 本地抽样总体不是 VST 词族总体

- 从本地 ECDICT 取 `frq > 0` 且词型、释义符合测试要求的有效词目，按 `frq`、词目文本稳定排序，最多保留 **20,000** 个。实际有效总数记为 `N`；最后一层可以少于 1,000。
- 以筛选后的本地名次 `r = 1…N` 分层：每 1,000 个有效词目一层。它是**本地排序后的千词目层**，不是原始语料排名的千词层，更不是 VST 的千词族层。报告应同时给出题库范围与有效总数。
- ECDICT 的 `frq`、`bnc` 是排名字段，`tag` 是考试标签，`exchange` 记录变形/lemma 信息 [6]。有这些字段不等于已按 VST 规则归并词族，也不等于题目经过难度标定。此方案只使用指定的 `frq` 抽样框，不把不同来源排名混作同一尺度。
- 一个本地词目是抽样与计数单位。同一词族的屈折或派生形式可能分别出现；没有明确归并、重建抽样框与验证时，不能把它称为词族，也不能用固定倍数换算。
- 排名不是出现次数，不能单凭排名或本地词目量给出文本覆盖率。考试词书标签可以用于学习分类，不能作为等距难度档或总体抽样层；中高考、四六级、GRE 等词表彼此重叠，选词目标也不同。

## 3. 离线概率模型：可计算，但未标定

以下均为**产品启发式配置**，不是上述论文提供的参数，也不是从本地学习者数据估计出的结果。

| 项目 | V1.4.2 约定 |
| --- | --- |
| 作答模型 | `P_i(θ) = c + (1-c) × sigmoid(a × (θ-b_i))` |
| 固定参数 | `a = 1.4`，`c = 0.25`，`b_i = ln((r_i + 100) / 1000)` |
| 数值积分 | `θ ∈ [-5, 7]`，步长 `0.05`；先验 `N(0, 2²)` |
| 能力更新 | 依据实际正确/错误作答更新后验，使用 EAP 及后验标准差 |
| 猜测处理 | 固定下限进入作答似然，不另加陷阱题、严谨度扣分或连对/连错升降档 |

四个实义选项之外另设“不认识”。它按未识别处理，不是第五个可猜中选项，故 `c` 不是 `1/5`；但 `0.25` 仍只是未知者在四个实义选项间均匀猜测的简化假设，不能代表实际猜测率。加入“不认识”会改变作答行为，本版本不是原版 VST 施测方式。

词频只提供难度先验。真实难度还受母语、专业经历、词义选择和干扰项影响；同词换一组释义/干扰项，也未必是同一道等难度题。固定相同区分度、猜测下限及单一潜在能力，是需后续检验的模型假设。

### 选题与停止

1. 先从每个本地层抽 1 题，确保全范围初始覆盖。
2. 然后按后验期望 Fisher 信息在欠覆盖层中选层，直到每层至少 2 题；之后在全范围自适应选层。**层内均匀随机选词**，这是受内容覆盖约束的自适应方案，不是始终挑出全题库信息量最大的单个词。
3. 至少 40 题、最多 80 题；满足各层至少 2 题且 EAP 后验标准差不高于 `0.30` 后才可提前结束。它是产品停止阈值，不保证词目量误差、外部准确率或所谓 95% 测量精度。
4. 全对、全错、边界集中、题量上限等需保留边界/完成状态；不能靠额外倍率抬高结果或把边界分数解释为精确能力。

题目应有唯一可辩护的答案；四个实义选项需避免同义歧义、词性/词形泄题及明显的长度提示。仅自动拼接词典释义不等于经过专家审题。测试期间只高亮已选项并提示“正在准备下一题”，不显示对勾、不反馈答案对错或估计值涨跌，避免提示和学习污染后续作答。

## 4. 报告量与区间

作答正确概率包含猜测下限，不能直接把 `ΣP_i(θ)` 叫“已知词目量”，否则 20,000 词目的总体即使极低能力仍会有约 5,000 的猜测底数。

定义去固定猜测底数后的模型识别概率：

```text
q_i(θ) = (P_i(θ) - c) / (1 - c) = sigmoid(a × (θ-b_i))
V(θ)   = Σ q_i(θ)，求和范围为全部 N 个本地有效词目
```

`V` 是模型推算的本地词目识别量，不是逐词验证的掌握数，不采用“本次正确率 × 整个词典大小”。点估计与区间应明确所用的后验汇总方法；若使用后验平均，则为 `E[V(θ) | 作答]`，不是一般情况下与其不同的 `V(E[θ | 作答])`。由于 `V(θ)` 单调，可将能力后验的 2.5% 与 97.5% 分位映射到词目量区间。

**95% 模型区间仅以固定参数、题库与先验为条件**，不包含未标定参数、题库筛选、题目歧义、词频代表性和模型错设的不确定性。不要称为经验证的总体置信保证；数值网格边界也不意味着真实能力到此为止。

按层可显示抽样数和模型参考值，但少量样本不能诊断“本层已掌握/通过”。层参考值受同一个能力模型支配，不是各层独立验证的掌握比例。只报告本地测量范围，不外推整个英语词汇、词族量、CEFR 或考试分数。

## 5. 数据隔离与后续验证

- 本轮优化按用户要求清空旧词汇量测试数据（会话、归档、历史与测试能力值），测试回到出厂状态；学习进度、词书、键位和预测掌握状态保留。清理只执行一次，之后的新测试正常累积。新旧量尺的模型与题库隔离规则仍保留在代码中。
- 新测验结果不自动应用到预测值、学习进度或学习队列。比较历史时还需区分算法/参数版本及题库变化。
- 下一步验证需要：固定且经审题的完整题目、目标学习者的足量作答数据、题目参数估计与模型拟合、局部依赖/差异项目功能检查，以及外部效标和复测证据。仿真与代码测试可以验证计算、边界和流程，不能替代心理测量标定。
