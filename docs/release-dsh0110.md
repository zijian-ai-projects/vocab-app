# DSH 0.1.10：默认最小化图标补丁（2026-11-17）

## 使用效果

- 安装插件后首次打开 DSH，以及以后重新打开或刷新页面，默认只显示原有的可拖动浮动图标，不自动弹出完整窗口；状态加载前后都不闪出卡片。
- 单击图标展开原 400×400 卡片；关闭后回到图标，再次单击恢复当前页面。窗口与图标的拖动、共享角锚点保持。
- 不持久化展开偏好，不迁移、不重算学习/测评记录。此状态仅在当前 React 组件内存中；新挂载总是最小化。
- 最小化不自动取到期复习，也不在隐藏的已答测验上发送自动下一题；展开后恢复原复习唤醒及可见测验 350ms 自动下一题。
- 原 0.1.9 的真实后台构建进度、四主题、历史删除、词书、快捷键和业务算法保持。

## 修改边界

产品代码仅修改 [客户端](<../dsh-plugin/client.js>) 的初始 hidden 状态与测验自动下一题的可见性保护，另更新 [版本清单](<../dsh-plugin/package.json>) 和 [随包说明](<../dsh-plugin/readme.md>)。没有修改 Host/Core、五份公开词库、Windows 源码或 Windows ZIP。补充测试及外部文档不进入运行包。

独立只读复查发现：仅改变初始 hidden 时，刷新期间拿到 `locked:true` 的测验仍会在 350ms 后后台 POST next。新增回归先复现了该问题（期望 0、实际 1），再加入 effect 的 hidden 依赖与定时回调 mountedRef/hiddenRef 双检查。关闭后尚未提交 React 渲染的短暂窗口也受到保护。
