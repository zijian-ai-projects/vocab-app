# V1.4.2 验收记录

## 范围

V1.4.2 用独立的词频分层与固定参数 3PL/EAP/CAT 实现取代活动测验旧 placement 算法。题型为四个真实释义加独立“不认识”；提交后只高亮选中项，顶部保留“已答 xx / 最多80”，不显示“正在准备下一题”、对勾或正误，不使用旧陷阱题、严谨度和连对连错阶梯。测验结果是本地词目识别量的模型估计，不应用于具体单词掌握预测。

本版界面优化：首次启动一次性清除旧测试数据（会话、归档、历史、测试能力值），测试回到出厂状态，学习进度、词书、键位、背景与预测掌握保留；去掉测试页说明小字与阶段提示、设置区版本号和题量小字、历史“报告”按钮、“查看保留的旧测验”入口、标题版本号与趋势说明小字；未完成记录显示“测试未完成”；历史每条展开后显示“本次已作答 xx 题，答对 xx 题。”；取消手动拖边缩放（只用窗口预设）；“开始新的测试”不再弹确认框；首次真实构建题库（包括重启后继续未完成测试）不会在隐藏窗口中预建，进度从 0 按构建阶段单调推进到 100，进度条相对整张卡片垂直居中、标题在其上方；折线图纵轴最低为 0；“测评说明”首次点击直接显示完整静态边界文字，不扫描、统计或构建题库；选择“不认识”只增加与释义选项相同的深色粗描边，原填充与文字颜色不变；正常测试结束显示“已答 xx 题 · 答对 xx 题”，居中的紧凑“知道了”按钮沿用设置控件主题配色并返回设置。

会话按算法、测量版本和题库内容指纹隔离；兼容会话从原开始时间起最多续测30天。工厂清理后不再有旧会话，但归档与量尺隔离逻辑保留。既有学习、预测、词书、自定义键位及未知扩展字段保留。

## 验证

使用 Windows Anaconda Python 3.8.3、PyQt 5.12.9。正式流程和 Qt UI 回归使用合成数据及 `ui_test_support.Sandbox`；性能定位使用的副本也只在隔离目录运行。真实个人进度、窗口文件及恢复文件只读字节快照守护，卡片写入统一使用Sandbox路径，不对真实文件做恢复性回写。

### 最新一轮：说明直显、构建页居中、答题计数与完成按钮

- 评测说明改用引擎公开边界（最多20,000词目、每1,000一层、最多20层）组成完整静态文字；首次点击返回时已是全文。测试用替身令 `FrequencyBank`、`population_summary`、`population_summary_steps` 一旦调用即失败，两个Qt平台均验证未调用、未建缓存、未保存记录，也没有计时器或准备态。
- 构建页用独立定位页，以整张卡片而非“标题+进度条”组合为基准：6px进度条中心与卡片垂直中心误差≤1px，标题固定在其上方。真实0→100阶段、100%后的校验/首题/首次原子保存连续构建页、成功无闪回和失败恢复原入口/尺寸均保留。
- 每次答案原子保存成功后立即显示“词汇测试 · 已答 N / 最多80”，350ms单次反馈节奏、只高亮所选项、重复提交锁和之后恰好推进一题不变；保存失败仍完整恢复会话、历史、容器别名及磁盘。
- 完成页“知道了”保留按文字自然宽度的紧凑居中几何，独立 `summaryOk` 样式只复用设置控件的 `chip_bg/chip_fg/chip_hover`。四主题渲染验证普通与悬停实色，520×430、640×520、760×620三档完成页仍逐项居中。
- 上一轮的设置定向刷新、测试单词下移、完成措辞、构建事务及全部科学边界继续通过同一套回归。

## 方法限制

固定 3PL 参数及本地词频排序未经学习者响应数据标定；报告区间以固定题库、先验与模型为条件，不覆盖所有测量误差。结果只描述本地有效词目中的书面词义识别，不是官方 VST 分数、词族总量、全部英语词汇、CEFR 或考试能力证明。方法、公式和文献边界详见[方法说明](vocabulary-assessment-v142.md)。

本次未启动使用真实个人资料路径的应用实例，未重建词库/词书，未安装依赖、提交、打标签或推送。
