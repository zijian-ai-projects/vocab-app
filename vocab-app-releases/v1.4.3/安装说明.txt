二、Windows 使用与升级
1. 将整个 ZIP 解压到新目录，运行其中 VocabApp.exe，不要在 ZIP 内运行。
   必须保留 _internal 和随包文件；不需要额外安装 Python/PyQt5/Node。
   目标 Windows 10/11 x64；未完成无开发环境干净机验收。
2. 学习资料优先保存在 EXE 旁 userdata；目录不可写时回退到
   %LOCALAPPDATA%\VocabAppWindows。VOCABAPP_DATA_DIR 可显式覆盖。
   不自动迁移源码或 DSH 的记录，也不把包内词库当学习资料。
3. 搬移或后续升级前先关闭应用并备份当前资料目录，不覆盖 userdata。
   ResetRecords.exe 是清空工具，不是升级工具，请勿为升级运行它。
4. 本次保留 UI 补丁的中性色“不认识”按钮和旧词忘记后保级、5 分钟复习规则。
   已保存 due 不重算；新规则在下次回答/改判生效。其它 CAT 算法和原词库保持。

三、SmartScreen 提示
本包 VocabApp.exe 的实际 Authenticode 状态为 NotSigned（未签名）。
“未识别的应用”通常表示文件或发布者信誉不足；这不是程序内部错误，
不等于已检出病毒，也不能作为安全保证。SHA-256 只能核对完整性，不是发布者签名。
“目前无法访问 SmartScreen”表示此次在线检查未完成，应确认一般联网正常后稍后重试；
受组织管理的设备请联系管理员。没有检查通过的依据时不要把联网失败视为安全认证。

四、DSH 使用与更新
1. DSH >=0.2.2-rc.1、Node >=24.9.0。本机 desktop 已安装并启用 0.1.10。
   其它 profile 请使用 DSH 的插件安装功能选择本 TGZ；刷新对应已登录 Web 页面。
   不启动替代服务器，不保证无需刷新自动更新。
2. 每次打开或刷新 DSH，默认只显示最小化图标，单击展开完整卡片；关闭后回到图标。
   图标仍可立即拖动；不保存展开偏好，不写入学习偏好。
   隐藏时不自动取到期复习、不自动跳过已答测验；展开后恢复原唤醒和 350ms 自动下一题。
   固定 400×400 迷你卡片，无尺寸档位或拖边缩放；可拖动位置、关闭再打开。
   历史行有紧凑删除按钮；加载页左上角留空，进度从 0 按真实后台构建增长，
   满格短留后进入题目。缓存题库不强行延迟。
3. 资料命名空间 dsh-vocab-app/vocab_app_default 保持；本机主记录与原备份
   已在升级时独立核对字节未变，未读取内容用于测试。
   DSH_HOME/storages/dsh-vocab-app 为默认资料位置；显式覆盖按原配置。
   它与 Windows 的 userdata/VocabAppWindows 相互独立，不自动导入或同步。
4. 备份前先停止本插件，再复制主 JSON 和 .bak。不在实例存活时强行删除锁。
   主文件损坏可由有效备份恢复；两者均坏时拒绝启动，不静默清空。
