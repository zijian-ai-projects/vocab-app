三、Windows 使用与安全升级
1. 先关闭旧 Windows 应用，找到并备份实际学习资料目录。
   通常在旧 EXE 旁 userdata；目录不可写时回退到 %LOCALAPPDATA%\VocabAppWindows。
   显式 VOCABAPP_DATA_DIR 覆盖优先。源码与 DSH 的记录位置相互独立，不自动导入。
2. 将整个新 ZIP 解压到新目录，运行其中 VocabApp.exe，不要在 ZIP 内直接运行。
   必须保留 _internal 和随包文件；无需另外安装 Python、PyQt5 或 Node。
3. 若学习资料在旧 EXE 旁 userdata：
   - 可将新包的运行文件更新到原应用目录，但不要覆盖或删除 userdata；
   - 或把已经备份的 userdata 复制到新 EXE 旁，确认记录正常后再自行整理旧目录。
   使用回退目录或显式覆盖目录的用户，继续沿用原资料配置即可。
4. ResetRecords.exe 是清空工具，不是升级工具。为本次升级不要运行它。
5. 本包目标 Windows 10/11 x64。已完成本机实际便携 EXE 启动/关闭和隔离原生 Qt 验证，
   尚未在无开发环境的干净 Windows 机器验收，不承诺所有机器都无环境问题。

四、SmartScreen 与完整性
新 VocabApp.exe 的实际 Authenticode 状态是 NotSigned（未签名）。
“未识别的应用”通常表示文件或发布者信誉不足，不等于已检出病毒，也不是安全保证。
SHA-256 只能核对文件完整性，不能代替发布者签名或安全扫描。
“目前无法访问 SmartScreen”表示在线检查未完成；确认一般联网后稍后重试，组织设备联系管理员。
没有检查通过的依据时，不要把联网失败当成安全认证。
只有已核实来源可信、散列一致并决定信任下载后，才可自行查看 ZIP“属性 → 常规”：
若有“解除锁定/Unblock”，选择并应用，再解压到新目录；没有该选项无需操作。
解除锁定只移除下载来源标记，不是签名、扫描或提高信誉，也不能保证所有安全提示消失。
若安全中心报告具体恶意软件或隔离，停止运行并保留防护。
本次未关闭 Defender/SmartScreen、添加排除、自动解除锁定或制作自签证书。
