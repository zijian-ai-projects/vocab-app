# DSH 背单词插件 · 0.1.11

0.1.11 调整新词答错后的重现规则，并修复缩小 DSH 窗口再还原时浮层/最小化入口位置无法恢复的问题；不改变既有词库、测评算法/记录版本、学习记录命名空间或默认最小化启动规则。

面向 DeepSeek Harness Web GUI 的本地浮层插件，包含刷词、四选一学习和词汇量测试。功能与测评基线仍为 Windows V1.4.3；**插件版本**与测评算法/记录版本是两回事。此前 0.1.9 更新（本补丁保留）：点击“开始新的测试”或继续测试后立即显示加载页，左上角不再重复显示加载文字。进度条从 0 开始，按真实题库构建进度平滑向右增长，完成后退出加载页；不再往返循环。首次构建移到本地后台线程，界面及状态读取不被耗时计算阻塞。请求失败后恢复原页面并显示重试入口，避免连点重复启动。历史记录页不显示“同题库、同量尺的完成测验趋势”小字，趋势图、历史摘要右侧的“删除”及结果页说明保持。窗口继续固定为迷你 400×400。此前的即时拖动、“下一个”整组居中与词书数量修复保持。Windows 仅提供仍标为 V1.4.3 的本地小补丁，刷词“不认识”底色与 DSH 对应主题一致。两端继续保留旧词不认识保级、5 分钟后再复习的规则，不更换词库、不清空个人记录。

## 操作与窗口

- 刷词正面：`Enter` 认识，`空格` 不认识；不再提供答题前的“显示释义”按钮或点词揭示。作答后的释义仍保留。
- 刷词背面：刚才回答认识时才显示透明的“选错了”，`空格` 把认识改判为不认识并进入下一词；刚才回答不认识时只显示长条“下一个 [空格 / Enter]”，标签与提示紧邻、整组居中。`Enter` 始终进入下一词，不可改判时 `空格` 也进入下一词。
- 选择题：四行对应 `[1]`、`[2]`、`[3]`、`[4]`；`空格` 不认识。作答后 `空格 / Enter` 进入下一词。
- 词汇量测试：点击开始/继续后立即显示中央加载提示和从 0 起步的进度条，左上角留空。后台线程使用原测评算法构建，进度条仅按真实进度平滑增长（遵循减少动态效果偏好），不显示百分比文字，不循环或按时间伪造进度；完成后直接进入题目。已缓存题库时无需重新构建，加载页可能很快消失。四个释义仍对应 `[1]`—`[4]`；下面第五行是居中的“不认识 [空格]”，没有 E 标签。它是“不认识”作答入口，**不是新增一个猜测释义**，模型的猜测参数没有改变。
- 历史记录：简洁摘要右侧显示普通底色的“删除”，折叠时也能操作；展开明细与删除互相独立。删除仍需确认，取消不会修改记录。
- 窗口固定为“迷你” **400×400**，不提供窗口大小设置。长内容可在内容区滚动，控件不应被裁切；窄视口会临时缩进可见范围。
- 原“标准/大窗”及“小窗”偏好只读映射为迷你，不重置学习记录。没有边框自由缩放。
- 标题栏可拖动；设置按钮位于学习页左上角。关闭后的浮动入口单击打开，左键按下即可拖动，与完整窗一样即时跟手，不再等待长按计时。完整窗和入口共享角锚点：窗口在屏幕左侧时关闭到原窗口左下角，右侧时关闭到右下角；拖动入口后还原完整窗沿同一锚点展开。缩小 DSH 应用窗口时只临时夹紧显示位置，放大/还原后恢复距所属左右边缘、底部的相对偏移，完整窗与最小化入口一致；再次拖动才改变首选位置。位置仍只保存在当前界面会话，窗口档位不再由用户设置。
- 选择词书：上方引导、中央列表、列表下的已学统计；进入主类后的子类行右侧只保留进入箭头，不显示词数；最细词书行名称后不再夹一份重复数量，只保留最右侧词数及下方已选书统计。底部左侧是词序与顺序/乱序，右侧是浏览词条与开始学习。

## 词汇量测试 · 方法与限制

以下说明参考现行 Windows 版的“评测说明”，已从 DSH 设置页面移到本文。移除说明入口不改变测评计算。

### 测量什么

本插件在本地词库中，按已有词频顺序筛选有效词目。量尺最多保留 **20,000 个有效词目**，每 **1,000 个**一层，最多 20 层；实际层数由可用词目决定。没有有效词频、释义不合适或超出范围的词不外推。

计数单位是**本地频率排名词条**（`frequency_ranked_entries`），不是英语全部词汇，也不是 VST 词族数、CEFR 等级或考试分数。它主要测书面接受性词义识别，不测主动回忆、拼写、听力或口语。

### 如何作答

从四个真实释义中选最贴近的一个；不认识时直接选择第五行“不认识”。没有“没有正确答案”的陷阱。选中的入口会高亮，但答题过程中不告知对错，以减少后续作答受即时反馈影响。

数字键 `[1]`—`[4]` 选择释义，`空格` 选择不认识。可暂停，首次开始后 **30 天内**续测；过期或不兼容的证据按既有规则归档，不重新评分后伪装成新记录。

### 如何选题与结束

先覆盖词频层，再根据 3PL 模型的**后验期望信息量**选择需要补测的层，层内随机且不重复抽词。通常至少 **40 题**并且每层至少 **2 题**后，后验标准差 ≤ **0.30** 时可自动结束；最多 **80 题**。小量尺也可能在可用题目耗尽时结束。

这些停止条件是产品规则，不是准确率保证。同一题库指纹、种子与作答序列会生成相同题序；此版未改变题库内容、随机数实现或选题规则。

### 如何估算

使用固定参数：

- 区分度 `a = 1.4`，猜测底数 `c = 0.25`；第五行“不认识”不会把底数改成 0.20。
- 难度 `b = ln((本地有效词目排名 + 100) / 1000)`。
- 能力先验 `N(0, 2²)`；在固定网格上计算后验与 EAP。
- 答错与不认识都作为未识别证据，没有“严谨度奖惩”。

估计量是对后验下每个词的**去猜测识别概率**求和，不是正确率乘词库总数，也不把 25% 猜测底数算作已掌握词汇。

### 区间与使用限制

题目难度和区分度**未经实测标定**。显示的 95% 模型区间只在当前固定参数与先验下成立，不涵盖题目歧义、词频偏差或模型不适配。稀疏的分层样本不能证明逐层或逐词掌握。

测试结果不直接改变学习队列、真实记忆等级或已有预测状态。分层记录是采样记录，不是逐层掌握诊断。历史比较应留意题库指纹、测量版本、量尺范围和兼容标记；不能把不兼容报告直接拼成增长趋势。

### 参考而非复刻

- VST：Nation & Beglar（2007），词频分层与接受性识别。
- CATSS：Laufer & Goldstein（2004），多强度模式自适应；不等同本实现的最大信息量 CAT。
- VCheck：WordEngine 开发方公开的 IRT/CAT 架构；其标定题库与完整算法未在本项目使用。

DSH 的算法标识仍为 `vst-cat-v143-web`，测量结构版本 3、会话结构版本 2。本轮学习排期和界面更新不换测评量尺、不重算旧报告。

## 词汇记忆等级

与 Windows 版一致，等级说明如下：

| 等级 | 含义 / 下一次复习间隔 |
| --- | --- |
| 0 | 新词，尚未认识，没有时间排期 |
| 1 | 5 分钟后复习 |
| 2 | 30 分钟 |
| 3 | 12 小时 |
| 4 | 1 天 |
| 5 | 2 天 |
| 6 | 4 天 |
| 7 | 7 天 |
| 8 | 15 天 |
| 9 | 30 天 |
| 10 | 已掌握，不再进入常规学习队列 |

认识新词进入 1 级；随后记得旧词升一级，并按表中的新等级间隔排期。忘记**不退级**：1—9 级旧词统一从这次“不认识”的回答时刻起 **5 分钟**后到期，再次不认识仍重新等 5 分钟，直到选择认识；0 级新词仍然没有 due。这个规则同样用于 Windows V1.4.3。升级不重新计算已经保存的 due，新规则在下一次回答或改判时生效。

学习中每次进入下一词都会先检查当前词书的到期旧词，再处理新词/待重试；不会在一题尚未作答时突然换词。空页有未来旧词排期时，会在到期后自动检查并显示复习词，不再只刷新状态。复习仍按选中词书顺序，学校范围的排除规则保留。5 分钟是到期时间，隐藏窗口、尚未完成当前题或不在当前词书范围时，不保证立刻显示。

0 级待重试不计作其它新词。忘记、改判为不认识或选错的新词只会在同一本书中已回答 **4 个其它首次新词**后重新出现；重现题、旧词复习、跳过/展示不计数。规则跨日累计，不在书末提前出现。书中没有候选时，只要它已到期，仍可作为当前题出现。到期复习优先于尚未到期的新词及其待重试；没有每日新词目标或其门禁。旧 `learning_policy` / `daily_new_ledger` 数据作为不透明扩展字段保留，不初始化、校验、记账或清除；学校暂停条件仍有效。

学校范围“已认识”或预测类标记不是额外的记忆等级。学习状态跨词书共享，但当前队列只使用选择的词书。词汇量测试不会直接改动这些真实等级。
